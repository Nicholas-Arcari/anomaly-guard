Evaluation

Detection quality

One seed and one operating point, the honest way (ADR-009): the threshold is set on 2,000 legitimate calibration requests at the target false-positive rate, then the test split is scored once. The intervals are 95% intervals for this test split: Wilson for the rates, a seeded bootstrap for the AUC. How much the results move from seed to seed is measured by the 20-seed experiment, npm run experiments (D-04). Accuracy is not shown on purpose: the classes are imbalanced.

Area under the curve

95% bootstrap interval

AUC is the probability that a random attack scores higher than a random legitimate request (ties count half): 0.5 is chance, 1 is perfect. It does not depend on the threshold. Rules only gives a single point (a rule matches or not), so its curve is two straight lines. The interval resamples the attacks and the legitimate requests of this test split 200 times (the experiments use 1,000).

Paired comparison (McNemar)

the same test requests · each detector at its own threshold for this target

Only the requests where two detectors disagree count. If both were equally good, each disagreement would be a coin flip, and the exact p-value says how surprising the split is (D-07). Attacks and legitimate requests are compared apart: on attacks, flagging more means catching more; on legitimate requests, more false alarms.
